# Project Profiles

이 폴더는 하나의 공통 템플릿에서 프로젝트 유형별 출발점을 제공한다.

- `formly-platform`: 주문, 결제, AI 생성, CMS, 배포 관리처럼 비밀값과 서버 기능을 다루는 운영 플랫폼
- `formly-customer-site`: 고객 도메인에 독립 배포되는 공개 홈페이지

새 프로젝트에는 한 프로필만 적용한다. 프로필의 `project-context.md`와 `.env.example`를 복사한 뒤 실제 기술 스택, 명령, 도메인, 배포 대상을 작성한다. 실제 비밀값은 복사하거나 커밋하지 않는다.
